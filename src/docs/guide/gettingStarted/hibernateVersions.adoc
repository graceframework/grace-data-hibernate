There are various changes you have to make to your build depending on the version of Grace framework when using Grace Data Hibernate {version}.

==== Grace framework 2024.2.x and above with Hibernate 5.6

Grace framework 2024.2.x is based on Spring Boot 3.5.x which enforces Hibernate 5.6.x as the default version.

[source,groovy]
.build.gradle
----
dependencies {
    implementation "org.graceframework:grace-boot-hibernate"
}
----
