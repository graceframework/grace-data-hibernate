GORM supports a number of powerful ways to query from dynamic finders, to criteria to Hibernate's object oriented query language HQL. Depending on the complexity of the query you have the following options in order of flexibility and power:

* Dynamic Finders
* Where Queries
* Criteria Queries
* Hibernate Query Language (HQL)

In addition, Groovy's ability to manipulate collections with https://docs.groovy-lang.org/4.0.27/html/documentation/#gpath_expressions[GPath] and methods like sort, findAll and so on combined with GORM results in a powerful combination.

However, let's start with the basics.
